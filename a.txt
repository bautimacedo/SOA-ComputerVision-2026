3. El telegraf.conf de la VM (¿se saca o no?)
No se saca. Queda como está. Este archivo monitorea la VM. Contenido:


[agent]
  interval = "10s"
  flush_interval = "10s"

[[outputs.influxdb_v2]]
  urls = ["http://influxdb:8086"]      # acá usa el nombre del contenedor, red interna de Docker
  token = "soa-token-2026"
  organization = "soa"
  bucket = "metrics"

[[inputs.cpu]]
  percpu = false
  totalcpu = true

[[inputs.mem]]

[[inputs.docker]]
  endpoint = "unix:///var/run/docker.sock"
  gather_services = false
  container_name_include = ["soa_app", "soa_db", "soa_nginx"]

[[inputs.http_listener_v2]]
  service_address = ":8186"            # escucha métricas custom de FastAPI
  paths = ["/telegraf"]
  data_format = "influx"
Diferencia clave con el de Bruno: el de la VM apunta a http://influxdb:8086 (nombre de contenedor, red Docker interna). El de Bruno va a apuntar a http://100.112.249.84:8086 (IP de Tailscale de la VM), porque Bruno está fuera de la red Docker.

4. Instrumentación del código FastAPI (ya está hecho)
Middleware global — app/middleware/metrics.py
Intercepta todas las requests HTTP y manda a Telegraf:

endpoint, method, status, duration_ms, error (0 o 1)
Se manda a http://telegraf:8186/telegraf por HTTP, con timeout de 1s y envuelto en try/except para que si Telegraf está caído no rompa la app.
Measurement: http_requests
S2 — tiempo de inferencia (app/business/s2.py)
Mide cuánto tarda YOLO y manda:

Measurement inference: duration_ms, success (0/1), object_count, tag model
S5 — embeddings y reconocimiento (app/controllers/s5.py)
Measurement embeddings: duration_ms, processed, valid, rejected
Measurement recognition: comparison_ms, success (0/1), confidence

6. Los dos fixes de nginx/Grafana que costaron (importante para Bruno)
Grafana detrás de nginx en un subpath dio dos problemas que ya están resueltos, pero conviene que queden documentados:

Problema 1 — Not Found: nginx no tenía el bloque de Grafana. Se agregó en nginx/nginx.conf:


location /grafana/ {
    proxy_pass http://grafana:3000/grafana/;   # OJO: termina en /grafana/, no solo en /
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-Proto https;
}
Problema 2 — ERR_TOO_MANY_REDIRECTS: Grafana entraba en loop de redirect. Se resolvió con GF_SERVER_PROTOCOL: http + GF_SERVER_SERVE_FROM_SUB_PATH: "true" en el compose, y con el proxy_pass terminando en /grafana/.

5. Verificación: En Grafana, en un panel de CPU, agregar a la query |> filter(fn: (r) => r.host == "bruno-pc"). Si aparecen datos, funcionó.

Las métricas de tiempo de inferencia, embeddings y reconocimiento aparecen solas cuando se usan los endpoints S2 y S5, con Bruno corriendo el inference service. No hay nada que configurar, solo usar el sistema.

8. Queries Flux de los 7 paneles (referencia)

# Tiempo promedio de inferencia
from(bucket:"metrics") |> range(start:v.timeRangeStart, stop:v.timeRangeStop)
  |> filter(fn:(r)=> r._measurement=="inference" and r._field=="duration_ms")
  |> aggregateWindow(every:v.windowPeriod, fn:mean, createEmpty:false)

# Imágenes procesadas por minuto
from(bucket:"metrics") |> range(start:v.timeRangeStart, stop:v.timeRangeStop)
  |> filter(fn:(r)=> r._measurement=="http_requests" and r._field=="duration_ms")
  |> aggregateWindow(every:1m, fn:count, createEmpty:false)

# Reconocimientos exitosos vs fallidos
from(bucket:"metrics") |> range(start:v.timeRangeStart, stop:v.timeRangeStop)
  |> filter(fn:(r)=> r._measurement=="recognition" and r._field=="success")
  |> aggregateWindow(every:v.windowPeriod, fn:sum, createEmpty:false)

# Tiempo de comparación vectorial
from(bucket:"metrics") |> range(start:v.timeRangeStart, stop:v.timeRangeStop)
  |> filter(fn:(r)=> r._measurement=="recognition" and r._field=="comparison_ms")
  |> aggregateWindow(every:v.windowPeriod, fn:mean, createEmpty:false)

# Uso de CPU
from(bucket:"metrics") |> range(start:v.timeRangeStart, stop:v.timeRangeStop)
  |> filter(fn:(r)=> r._measurement=="cpu" and r._field=="usage_percent")
  |> aggregateWindow(every:v.windowPeriod, fn:mean, createEmpty:false)

# Uso de memoria
from(bucket:"metrics") |> range(start:v.timeRangeStart, stop:v.timeRangeStop)
  |> filter(fn:(r)=> r._measurement=="mem" and r._field=="used_percent")
  |> aggregateWindow(every:v.windowPeriod, fn:mean, createEmpty:false)

# Tasa de errores
from(bucket:"metrics") |> range(start:v.timeRangeStart, stop:v.timeRangeStop)
  |> filter(fn:(r)=> r._measurement=="http_requests" and r._field=="error")
  |> aggregateWindow(every:v.windowPeriod, fn:sum, createEmpty:false)
